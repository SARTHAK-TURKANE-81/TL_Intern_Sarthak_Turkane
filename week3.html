MICROCONTROLLER & IoT PLATFORM

ESP32 Technology

ESP32 is a powerful, low-cost microcontroller developed by Espressif Systems. It combines processing capabilities with built-in Wi-Fi and Bluetooth connectivity, making it one of the most widely used platforms for Internet of Things (IoT) applications.

Key Specifications

Processor

Dual-Core Xtensa LX6 running up to 240 MHz clock speed for high-performance embedded tasks.

Memory

520 KB SRAM with support for external flash. Suitable for moderate data processing workloads.

Wireless

Integrated Wi-Fi and Bluetooth support enables seamless IoT connectivity without external modules.

GPIO & Peripherals

34 GPIO pins with 18 ADC channels, 2 DAC channels, and PWM support for versatile interfacing.

Power

3.3V operating voltage with Deep Sleep power-saving mode for battery-powered deployments.

Development

Compatible with Arduino IDE, ESP-IDF, and MicroPython with a large active community ecosystem.

Applications

IoT & Connectivity

  • Smart Home Systems
  • Wireless Sensor Networks
  • Industrial IoT Monitoring
  • Remote Data Logging

Embedded & Robotics

  • Robotics Control Systems
  • Healthcare Monitoring Devices
  • Industrial Automation
  • Real-Time Sensor Processing
Learning Outcome:
ESP32's combination of processing power, wireless connectivity, and low cost makes it an ideal platform for IoT and Physical AI applications, particularly for real-time data acquisition and remote monitoring systems.

Arduino Mega

  • Large form factor
  • Digital Pins: 54
  • Analog Inputs: 16
  • Flash: 256 KB

Physical AI refers to intelligent systems that can perceive, reason, and act within the physical world. Unlike traditional AI that operates purely in software environments, Physical AI enables machines to interact with real-world surroundings through a continuous sense-reason-act loop.

Core Mechanism — Sense → Reason → Act

1. Sensing

Environmental data is collected through physical sensors.

  • Camera
  • LiDAR
  • Ultrasonic Sensor
  • Temperature Sensor

2. Reasoning

Collected data is processed using AI algorithms.

  • Deep Learning
  • Computer Vision
  • Vision-Language-Action Models

3. Actuation

The system executes decisions through physical actuators.

  • Motors
  • Robotic Arms
  • Hydraulic Systems

Learning Outcome:
Physical AI closes the loop between perception and action, enabling systems like autonomous robots, healthcare diagnostics, and real-time monitoring to operate intelligently in dynamic environments.

HARDWARE ARCHITECTURE

Microcontroller vs Processor

Understanding the distinction between microcontrollers and processors is essential for selecting the right hardware platform for any embedded or AI application.

Head-to-Head Comparison

⚙ Microcontroller

Compact integrated circuits designed for specific control tasks with minimal overhead.

  • Examples: Arduino, ESP32, STM32
  • Low Power Consumption
  • Real-Time Control Capability
  • Dedicated Task Execution
  • No OS Required

🖥 Processor

Designed for complex computing operations and multitasking with high performance.

  • Examples: Raspberry Pi, Intel, AMD
  • High Processing Power
  • Multitasking Support
  • Requires Operating System
  • Higher Power Consumption

Learning Outcome:
For real-time control tasks, microcontrollers are the optimal choice. For AI inference and complex computation like the Skin Cancer Detection project, a processor-level device like Raspberry Pi 4 is required.

DISTRIBUTED COMPUTING MODEL

Edge Computing

Edge Computing is a distributed computing model where data processing occurs close to the data source rather than a centralized cloud server. For latency-sensitive and privacy-critical applications, edge computing provides significant advantages over traditional cloud-based approaches.

Why Edge Computing?

Faster Response

Processing at the source eliminates round-trip cloud latency, enabling near-instant real-time decisions.

Reduced Bandwidth

Only results or processed summaries are transmitted, drastically reducing network consumption.

Improved Privacy

Sensitive data such as medical images never leaves the local device, ensuring patient data security.

Real-Time Decision Making

Critical applications like autonomous vehicles or medical diagnostics require millisecond-level responses.

FEEDBACK & REGULATION SYSTEMS

Control Systems — P, PI & PID

Control systems regulate machine behavior automatically by continuously monitoring output and adjusting inputs to minimize error. Three controller types were studied: P, PI, and PID, each offering increasing levels of accuracy and stability.

P Controller

Output depends only on the present error value.

  • ✅ Simple implementation
  • ✅ Fast response
  • ⚠ Steady-state error remains

PI Controller

Combines proportional and integral control to eliminate steady-state error.

  • ✅ Eliminates steady-state error
  • ✅ Stable operation
  • Used in: Motor & temperature control

PID Controller

Combines all three terms for highest accuracy, speed, and stability.

  • ✅ High accuracy
  • ✅ Fast response
  • ✅ Excellent stability
  • Used in: Robotics, drones, automation
Learning Outcome:
PID controllers are the industry standard in precision automation systems. Understanding their behavior is critical for designing stable, responsive control loops in robotics and embedded systems projects.

PERCEPTION & MEASUREMENT

Sensors Documentation

A sensor converts physical phenomena into measurable electrical signals. Sensors are categorized as Active (require external power) or Passive (respond to environmental changes without external energy input).

Active Sensors

Ultrasonic Sensor

Working Principle: Uses sound waves to measure distance by calculating time-of-flight of reflected pulses.

Range: 2 cm – 400 cm

  • Obstacle Detection
  • Robotics Navigation
  • Parking Assistance Systems

LiDAR Sensor

Working Principle: Uses laser pulses to calculate precise distances and create 3D environment maps.

Range: Up to several hundred meters

  • Autonomous Vehicles
  • 3D Mapping Systems
  • Advanced Robotics
Passive Sensors

LDR (Light Dependent Resistor)

Working Principle: Resistance changes proportionally with ambient light intensity.

  • Automatic Street Lighting
  • Light Monitoring Systems
  • Display Brightness Control

Thermistor

Working Principle: Resistance changes according to temperature variation.

  • Temperature Monitoring
  • Medical Diagnostic Devices
  • Industrial Thermal Control
Learning Outcome:
Selecting the correct sensor type is fundamental to system accuracy. Active sensors like LiDAR provide precision at the cost of power; passive sensors like thermistors offer simplicity with minimal energy overhead.

MOTION & MECHANICAL ACTUATION

Actuators & Motors

Actuators translate electrical control signals into physical mechanical action. Five major motor types were studied, each with distinct operating principles and application suitability.

Induction Motor (AC)

Operates on AC supply through electromagnetic induction. Widely used in industrial machinery and high-power applications.

DC Motor

Powered by direct current with straightforward speed control via voltage adjustment. Common in robotics and consumer devices.

Stepper Motor

Rotates in precise discrete steps, providing positional accuracy without feedback. Ideal for CNC machines and 3D printers.

BLDC Motor

Brushless design eliminates mechanical wear, delivering high efficiency and reliability. Used in drones and electric vehicles.

Servo Motor

Closed-loop control with position feedback delivers extremely precise angular control. Standard in robotics and aerospace.

SWITCHING & POWER CONTROL

MOSFET & Relay

MOSFETs and Relays are the two primary technologies used for switching and power control in embedded and IoT systems, each suited to different voltage, speed, and isolation requirements.

MOSFET — Metal Oxide Semiconductor Field Effect Transistor

Terminals & Types

  • Gate — Control input terminal
  • Drain — Output current terminal
  • Source — Reference terminal
  • N-Channel: Higher efficiency, widely used
  • P-Channel: High-side switching

Advantages & Applications

  • High Switching Speed
  • Low Power Loss
  • Motor Drivers & H-Bridge Circuits
  • Power Supply Regulation
  • Battery Management Systems
  • Robotics Drive Circuits
Relay — Electrically Operated Switch

Key Advantages

  • Complete electrical isolation between control and load circuits
  • Controls high voltage loads using low voltage microcontroller signals
  • Simple to interface with Arduino and ESP32

Applications

  • Home Automation Systems
  • Industrial Equipment Control
  • Smart Appliance Switching
  • AC Load Control via Microcontroller
Learning Outcome:
MOSFETs are preferred for high-speed, low-loss switching in DC circuits, while Relays are used when electrical isolation is critical or when switching AC mains loads from low-voltage controller circuits.

CLOUD IoT INTEGRATION

ESP32 & Firebase

Firebase is a cloud-based platform by Google that enables real-time data synchronization between multiple devices. When combined with ESP32, it creates a powerful bi-directional IoT communication channel for remote monitoring and control applications.

Write & Read Operations

ESP32 → Firebase (Write)

ESP32 sends data to the Firebase Realtime Database for cloud storage and multi-device access.

  • Sensor Readings
  • Temperature & Humidity Values
  • Device Status Updates

Firebase → ESP32 (Read)

ESP32 receives commands and configuration from Firebase, enabling remote device control.

  • LED ON/OFF Commands
  • Motor Control Signals
  • Remote Device Settings
System Architecture

ESP32 Device → Firebase Database → Mobile App / Web Dashboard

ESP32 Device 1 ↔ Firebase Realtime DB ↔ ESP32 Device 2

ESP32 Device 3 ↔ Firebase Realtime DB ↔ Web Dashboard

Advantages of ESP32 + Firebase

Real-Time Sync

Data changes propagate instantly across all connected devices and dashboards without polling.

Remote Monitoring

View live sensor data and device status from anywhere in the world via a mobile or web interface.

Multi-Device Communication

Multiple ESP32 devices can read and write to shared data nodes, enabling coordinated IoT systems.

Cloud Storage

Historical sensor data is persisted in the cloud for trend analysis, logging, and remote diagnostics.

Learning Outcome:
The ESP32–Firebase integration provides a complete IoT communication pipeline, enabling both real-time remote monitoring and bidirectional device control — essential for connected healthcare and smart automation systems.
