Day 1 - GitHub & VS Code Setup

Simple step-by-step documentation with videos

The first day of the project marked an important starting point in transforming an idea into a structured and trackable workflow. The day began with creating a new repository on GitHub, establishing a dedicated space for managing the project and maintaining version control throughout development. Once the repository was created, it was cloned to the local system using Git commands through the terminal, allowing the project environment to be set up locally. After configuring the repository, the project was opened in Visual Studio Code for development. An HTML-based progress tracker was then designed and added to the repository folder. The files were organized systematically to maintain a clean and manageable project structure from the very beginning. A significant learning experience from the day was understanding the capabilities of GitHub Pages. It was interesting to discover that HTML files stored within a GitHub repository can be hosted directly as live webpages, enabling projects to be presented and shared online efficiently. The day also included attending an insightful session conducted by Dr. Kiran Wakchaure and Dr. Tanay Ghosh. The session focused on GitHub integration with IDEs, understanding workflow fundamentals, and learning practical GitHub productivity techniques. The discussion provided valuable insights into maintaining efficient development practices and managing repositories effectively. Finally, the completed files were uploaded to GitHub using the standard Git workflow: git add . git commit -m "Added internship tracker files" git push Successfully pushing the first commit to the repository marked the official beginning of the project development journey.

Day 2 - Research & Software Exploration

Simple documentation with videos of software exploration

The second day of the internship was focused on research, planning, and understanding the software ecosystem that would support the development process throughout the project journey. Rather than directly building features, the day was dedicated to exploring the tools that play an essential role in design, modeling, documentation, content creation, and workflow management. This phase was important in creating a clearer understanding of how different technologies connect together during real-world project development. The exploration began with learning the fundamentals and applications of Autodesk Fusion and SolidWorks, two widely used CAD and product design platforms. Their capabilities in 3D modeling, mechanical design, prototyping, and simulation highlighted how digital concepts can be transformed into manufacturable designs. The day also included learning about creative and documentation tools such as GIMP, Canva, and Inkscape. These tools demonstrated how visual communication, vector graphics, presentations, and design assets can contribute to professional project documentation and presentation quality. In addition, media and workflow-related tools were explored, including OBS Studio for screen recording and content capture, along with FFmpeg for media processing, compression, and file conversion. Understanding these tools provided insight into managing recordings, demonstrations, and digital assets efficiently during development. An important realization from the day was understanding that successful projects are not built using a single software platform alone. Instead, they rely on an interconnected workflow where multiple tools contribute to different stages such as ideation, design, prototyping, documentation, collaboration, and presentation.

Day 3 - Autodesk Fusion Basics

Step-by-step CAD learning documentation with videos

The third day of the internship marked the beginning of hands-on work with Computer-Aided Design (CAD) tools through Autodesk Fusion. The session focused on understanding the fundamentals of digital product design and how ideas can gradually be transformed into manufacturable 3D models. The learning journey started with an introduction to the Autodesk Fusion interface, where different design environments, tools, and workflows were explored. Understanding the workspace layout and navigation controls provided a strong foundation for working efficiently within the software. The session then moved into sketch creation, which forms the core of most CAD modeling workflows. Basic 2D sketches were created while learning how dimensions, constraints, and scaling are used to define accurate geometries. This helped in understanding how precision plays an important role in engineering and product design. As the session progressed, the workflow of converting 2D sketches into 3D models was introduced. Learning how flat sketches can evolve into solid objects provided valuable insight into the process of digital prototyping and model development. Another important aspect covered during the session was understanding how CAD models can be prepared for 3D printing. This introduced the concept of rapid prototyping, where digital designs can be transformed into physical objects using additive manufacturing technologies. One of the most memorable moments of the day was creating the very first sketch successfully. Although simple, it represented the first practical step into the field of CAD design and digital fabrication — a small achievement that made the learning experience even more exciting.
